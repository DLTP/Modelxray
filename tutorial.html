🔢 Calculator 📖 How It Works

How We Built This AI Model

A step-by-step walkthrough of how a Neural Network learns to be a calculator.

📐 1. Deciding the Model Size
Before writing any code, we need to decide: How big should our AI's brain be?

Our calculator takes 3 inputs: Number 1, an Operator (+, -, *, /), and Number 2.

But wait — we can't just feed the operator as a letter. AI models only understand numbers! So we encode the operator as 4 separate slots using a technique called One-Hot Encoding:
  • + becomes [1, 0, 0, 0]
  • - becomes [0, 1, 0, 0]
  • * becomes [0, 0, 1, 0]
  • / becomes [0, 0, 0, 1]
So our total input is: [Num1, op_plus, op_minus, op_mul, op_div, Num2] = 6 numbers.

That means our Input Layer has 6 neurons.
🤔 2. Why One-Hot Encoding?
Why can't we just use 1 for +, 2 for -, 3 for *, 4 for /?

Great question! If we did that, the AI would think * (3) is "bigger" or "more important" than + (1). It would also think / (4) is somehow "close to" * (3).

One-Hot Encoding treats every operator as completely independent. No operator is "bigger" than another. Each operator gets its own dedicated on/off switch.

This is the standard technique used in ChatGPT, image classifiers, and nearly every AI model in production today!
🧱 3. Why 8 Hidden Neurons?
Our architecture is: Input[6] → Hidden[8] → Hidden[8] → Output[1]

Why 8? The hidden layers are where the AI does its "thinking." Each neuron in a hidden layer is like a tiny expert that learns one specific pattern.

  • Too few neurons (e.g. 2)? The AI can't learn complex patterns like multiplication.
  • Too many neurons (e.g. 256)? Works great, but the matrices become unreadable on screen! Also wastes memory.
  • 8 neurons? Perfect balance — enough capacity to learn 4 operations, small enough to display the actual numbers in every cell.
In production AI, models use thousands or millions of neurons. But the math is exactly the same — just bigger grids!
🎲 4. What Does the Code Look Like?
Here is the actual Python code that defines our entire model. That's it — just 6 lines! 
class CalcNet(nn.Module):
    def __init__(self):
        self.fc1 = nn.Linear(6, 8)    # Input → Hidden 1 (6×8 weight matrix)
        self.fc2 = nn.Linear(8, 8)    # Hidden 1 → Hidden 2 (8×8 weight matrix)
        self.out = nn.Linear(8, 1)    # Hidden 2 → Output (8×1 weight matrix)
        self.relu = nn.ReLU()           # Activation: kill negatives

    def forward(self, x):
        x = self.relu(self.fc1(x))     # Step 1: Multiply + filter
        x = self.relu(self.fc2(x))     # Step 2: Multiply + filter
        return self.out(x)              # Step 3: Final answer

🦁 1. The AI Zoo
AI is not a single machine. It is a family of methods with different strengths. Our calculator is a form of supervised learning — the model learns from examples where the correct answer is already known.
Supervised Learning

Learn from labeled examples. The calculator sees inputs like [7, 0, 0, 1, 0, 8] and the answer 56. Examples: regression, classification, calculator models.

Unsupervised Learning

Find hidden structure without answers. The system groups or compresses data on its own. Examples: clustering, dimensionality reduction.

Generative AI

Create new content from patterns learned in data. The model becomes a writer, artist, or composer. Examples: ChatGPT, image generators.

⚙️ 2. What is a training example?

🧠 3. The model is just weights and biases
The neural network stores its learned knowledge in two kinds of arrays:
  • Weights: the main numbers that connect one layer to the next.
  • Biases: extra offsets that help the network shift its outputs.
In C/C++ terms, these are like float w1[32][6], float b1[32], and so on.
During inference, the computer performs a few loops of multiply-add operations, just like matrix math in C.
💻 4. C/C++-style inference walkthrough
Here is a simplified C-style version of the same math the web app does when it predicts a result. It shows how the weights and activations are stored and how the output is computed. 
// input vector: [x0, op_plus, op_minus, op_mul, op_div, x1]
float x[6] = {var1, op_plus, op_minus, op_mul, op_div, var2};

// hidden layer outputs
float a1[32];
float a2[32];
float a3[32];

// Layer 1: input -> hidden
for (int i = 0; i < 32; i++) {
    float sum = b1[i];
    for (int j = 0; j < 6; j++) {
        sum += x[j] * w1[i][j];
    }
    a1[i] = sum > 0 ? sum : 0; // ReLU activation
}

// Layer 2: hidden -> hidden
for (int i = 0; i < 32; i++) {
    float sum = b2[i];
    for (int j = 0; j < 32; j++) {
        sum += a1[j] * w2[i][j];
    }
    a2[i] = sum > 0 ? sum : 0;
}

// Layer 3: hidden -> hidden
for (int i = 0; i < 32; i++) {
    float sum = b3[i];
    for (int j = 0; j < 32; j++) {
        sum += a2[j] * w3[i][j];
    }
    a3[i] = sum > 0 ? sum : 0;
}

// Output layer: hidden -> result
float sum = bout[0];
for (int j = 0; j < 32; j++) {
    sum += a3[j] * wout[0][j];
}
float raw_output = sum;
float real_output = raw_output * y_std + y_mean;
This is the exact structure of the calculator logic. The only differences are the array sizes and the model values.
💾 5. C-style training loop
Training is the process of adjusting the weight arrays so the predictions get closer to the correct answers. Here is a simple C-style sketch of the same training steps the Python script takes. 
for (int epoch = 0; epoch < 20000; epoch++) {
    // 1. Forward pass: compute prediction for all examples
    float y_pred[N][1];
    for (int i = 0; i < N; i++) {
        y_pred[i][0] = model_forward(X[i]);
    }

    // 2. Compute loss: mean squared error
    float loss = 0;
    for (int i = 0; i < N; i++) {
        float diff = y_pred[i][0] - Y_norm[i][0];
        loss += diff * diff;
    }
    loss /= N;

    // 3. Backward pass: compute gradients for each weight and bias
    compute_gradients(X, Y_norm, y_pred, grads);

    // 4. Update weights: move values slightly in the right direction
    for (int j = 0; j < num_weights; j++) {
        weights[j] -= learning_rate * grads[j];
    }
}
The details of gradient calculation are hidden inside compute_gradients(), but the important part is the loop: predict, measure error, and update. In train.py, this happens with PyTorch calls such as outputs = model_full(X), loss.backward(), and optimizer.step().
🌳 6. One tree vs. a whole forest
A decision tree follows rules like an if/else chain. A random forest combines many trees to reduce mistakes. Neural networks are different: they learn numbers, not rules.
